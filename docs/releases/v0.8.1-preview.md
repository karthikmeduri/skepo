# Skepo 0.8.1 Windows preview

This preview packages the provider-reliability changes developed after 0.8.0.
It is not completion of the twelve-milestone roadmap.

## Included

- Preserved workflow/ledger instructions and removed duplicate bot personas.
- Corrected Claude and Ollama token accounting.
- Rejected provider error envelopes and interrupted streams instead of treating
  partial output as a successful result.
- Improved stream cleanup, request deadlines and pre-dispatch cancellation.
- Added local HTTP cancellation regression coverage across provider formats.

## Install and test

Download `Skepo-Setup-0.8.1.exe` from this release and run it on Windows.
The installer is unsigned; Windows may display a publisher warning.
Only proceed if you trust this repository and the downloaded artifact.

Back up any existing Skepo workspace first. Use a separate, empty test workspace
on your chosen drive. Existing application settings may be shared with 0.8.0;
this is not an isolated side-by-side installation.

For the planned offline test, start Ollama with an already downloaded model,
select Ollama for every bot and verify the model selection before running.
Do not configure cloud API keys or run browser tasks during the initial test.
No models are bundled in this installer.

Suggested checks: launch, choose a workspace, create a bot, send a short prompt,
cancel a longer response, reopen the app, and inspect saved conversations/notes.
Then try a small approved team task using only local models.

## Validation and limitations

Build verification: all 70 tests passed, TypeScript and frontend production
build passed, and the Windows x64 NSIS installer was generated successfully.
The packaged application archive was inspected to verify version 0.8.1 and
the compiled cancellation and usage-accounting fixes.

Installer size: 84,996,881 bytes. SHA-256:

```text
E1277C21A65BA697F06D1324996F18E12BE91EBC929F6FC3063F025E05568FF1
```

Automated regression tests use mocked providers and local HTTP fixtures only.
No paid API calls or live Ollama inference were used for this release build.
Installation, desktop acceptance and the user's offline models still require
testing. macOS is not packaged or tested. Performance/resource savings are not
claimed. SQLite memory and the planned rich HTML/Markdown memory system remain
unfinished; see the development cadence for remaining roadmap scope.
